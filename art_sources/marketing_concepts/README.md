# Mirexis marketing concept art

This folder contains promotional concept art created on 2026-09-02. These images are not wired into the game runtime and are intended for store-page exploration, social posts, trailer frames, and campaign mood boards.

## Set

- `mirexis_marketing_hero_colony_between_powers.png` — wide campaign hero: the colony caught between Directorate, Brood, and Ascendant forces.
- `mirexis_marketing_colony_commons.png` — vertical character-and-home image: survivors repairing equipment and planning inside the colony Commons.
- `mirexis_marketing_three_powers.png` — square faction-contrast tile: readable visual identities for the three external powers.
- `mirexis_marketing_tactical_push.png` — wide action frame: a squad using cover, rescue, and objective interaction under pressure.
- `mirexis_marketing_mutation_spotlight.png` — vertical character spotlight: a recruit confronting the promise and danger of mutation.
- `mirexis_marketing_world_mire_and_ruins.png` — wide environment art: Mirexis wetlands, the tiny human foothold, and the buried Ascendant ruins.

## Prompt set

All six images were generated with the built-in ImageGen workflow, using the existing Mirexis title screen, recruit portraits, enemy reference board, terrain key, and finished concept art as visual references. The prompt set focused on:

1. one colony caught between three powers;
2. the colony as a lived-in home;
3. clear Directorate / Brood / Ascendant faction contrast;
4. tactical survival through cover, rescue, and objective work;
5. mutation as a personal choice with consequences;
6. the hostile beauty and scale of the Mirexis environment.

Shared constraints were no text, logos, watermarks, or HUD; grounded survival technology; near-black, teal, rust-orange, signal-red, crimson, cyan, and violet palette; and polished painted sci-fi concept-art rendering consistent with the current character references.
